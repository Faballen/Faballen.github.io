01 — UnmaskMedia

AI Media Verification Platform

A multi-service application designed to analyze uploaded media and return an AI-assisted verification result.

Application Screenshots

Engineering Focus

  • Separate mobile, API, and AI responsibilities into independent services.
  • Use Spring Boot as the application/business layer between the Android client and AI service.
  • Keep media processing isolated from the core backend.
