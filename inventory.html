02 — Inventory and Revenue Tracker

Inventory and Revenue Tracker

An inventory management Android application that allows users to create and manage item listings, track inventory costs and quantities, record sales, and automatically calculate profit or loss.

Architecture

                +-----------------------+
                | UI Layer              |
                |   UI Elements         | 
                |   State Holders(VM)   |
                +----------+------------+
                           | 
                           |
                +-------------------------+
                |Data Layer               | 
                |   Repositories          |
                |   Room Database         |
                |   Data Access Objects   |
                +-------------------------+

        Android App ---------> Item and Sales Data
        Room Database ----------> Profit and Loss Calculations

Technology

Android
  • Kotlin
  • Jetpack Compose
  • Coroutines / Flow
  • MVVM / UDF
  • Material Design 3
  • Photo capture and upload
Backend & Data
  • Room Database
  • REST API
  • Bitmap
  • AI & Machine Learning (Google Gemini API)
  • Multi-Modal Vision AI

Application Screenshots

Features

  • Create and manage item listings with costs, quantities, categories, and conditions.
  • Capture or upload photos for inventory items.
  • Record sales and automatically calculate profit or loss.
  • View detailed inventory, sales history, and individual sales details.
